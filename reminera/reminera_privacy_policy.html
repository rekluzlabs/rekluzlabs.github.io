Privacy Policy for Reminera

App: Reminera (Family Memory Recording)

Package: com.rekluzlabs.reminera

Developer: Rekluz Labs

Last updated: July 29, 2026

Data collection baseline

Reminera runs offline. The app has no accounts, no logins, and no servers managed by Rekluz Labs. Every photo, video, audio recording, biography entry, and family relationship stored in the app stays on the local device.

The app does not collect or transmit the following items:

  • Analytics, telemetry, or app usage statistics
  • Advertising identifiers or device tracking IDs
  • Crash reports or automated error logs sent to external platforms
  • Personal media files, audio recordings, or family history records

Reminera contains zero advertisements and includes no third-party advertising or tracking SDKs.

On-device data storage

All data generated or imported by the user resides in sandboxed application storage:

  • Media files: Recorded photos, videos, and audio clips are saved directly in app-private storage at filesDir/recordings/, along with internal copies of imported media files.
  • Database records: Family profiles, story entries, biographies, and memory metadata are managed locally through an on-device Room database.
  • Generated documents: Compiled PDF books are held in internal storage until the user manually exports or shares them.
  • Settings: Theme and app configuration values are saved locally.

Android permissions

Reminera requests specific Android system permissions strictly to perform local media operations:

  • CAMERA: Captures photos and video clips within the app interface.
  • RECORD_AUDIO: Records voice notes and audio for internal video generation.
  • System Photo and Document Pickers: Imports external photos, videos, or audio files without granting the app full system storage access.
  • Storage export: Writes exported PDF documents or exported media directly to DCIM/Reminera only when explicitly requested by the user.

Google Gemini API processing

Reminera provides an optional feature to rephrase biography notes into structured text using Google's Gemini API. This feature relies on a bring-your-own-key (BYOK) design:

  • Disabled by default: AI text generation remains completely inactive until a user inputs their personal Google Gemini API key in app settings. Rekluz Labs holds no keys and operates no proxy servers for this requests pipeline.
  • Text-only transmission: Requests transmit plain text biography notes capped at 20,000 characters. Photos, video files, and audio recordings are never sent to the API.
  • Manual execution: Text transmits directly to Google only when the user explicitly taps "Generate" or "Regenerate". The app initiates no background or automated transmissions.
  • Key security: The API key is stored locally on the device inside Android's EncryptedSharedPreferences, backed by hardware-level storage in the Android Keystore. The key transmits directly to Google's API endpoints to authenticate requests.
  • Consent and reset: The app displays a dedicated consent dialog before the first API request is sent. Users can revoke consent or clear the saved API key at any time from app settings.

Third-party records and family data

Users may record information about extended family members or minors inside Reminera. All family records stay on the local device under the sole control of the device owner. Rekluz Labs has no access to any stored profiles or media files. Device owners remain responsible for obtaining required consent from family members or legal guardians before logging their personal information.

Data retention and removal

Because all records remain local to the device:

  • Users can delete individual recordings, story entries, or profiles directly inside the app interface.
  • Uninstalling Reminera permanently removes the Room database, saved media files, encrypted preferences, and generated PDFs from device storage.
  • Rekluz Labs holds no account backups and cannot restore or delete data remotely.
