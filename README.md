# Rekluz Labs Website
</p>
Source code for the [Rekluz Labs](https://rekluzlabs.github.io) website — the official landing page for Rekluz Labs, an independent Android development studio building privacy-first, ad-free apps and games.

🔗 **Live site:** [rekluzlabs.github.io](https://rekluzlabs.github.io)

---

## About

Rekluz Labs is an independent studio focused on **privacy-first, ad-free Android apps and games**, built with care and a strong attention to detail.

This repository contains the static site serving as the studio's web presence, showcasing current releases and apps in development.

---

## Technologies

- **HTML5 / CSS3**
- **JavaScript**
- **GitHub Pages** (hosting)

---

## Deployment

This site deploys automatically via GitHub Pages from the `main` branch.

Changes pushed to `main` go live at [rekluzlabs.github.io](https://rekluzlabs.github.io) within a few minutes.
