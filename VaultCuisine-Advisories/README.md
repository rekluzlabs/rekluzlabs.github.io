# VaultCuisine Model Advisories

Maintained by **Rekluz Labs**

## Purpose

This repository provides publicly accessible AI model advisory information for VaultCuisine, an offline-first Android recipe management application.

The advisory catalogue supplements Google's official Gemini model discovery API with additional information concerning:

- Model compatibility
- Supported recipe-processing capabilities
- Model deprecation and retirement
- Recommended replacement models
- Provider-side model redirection
- Free-tier and paid-tier availability
- Model access restrictions

## How it works

VaultCuisine retrieves model availability directly from Google's official Gemini API and uses the advisory information in this repository to refine its model selection interface.

Advisory updates can be delivered without requiring a new VaultCuisine application release.

## Privacy

This repository contains public model metadata only.

It does not contain:

- VaultCuisine application source code
- API keys or credentials
- User information
- Recipes or photographs
- Personal or private data

## Accuracy

Advisory information is based on available official provider documentation. Model availability, compatibility, pricing and account eligibility may change.

VaultCuisine never automatically changes a user's selected AI model.
